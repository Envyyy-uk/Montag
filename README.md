# Автомонтаж (auto-editor)

Особиста програма, яка з кількох сирих відео робить майже готовий монтаж: кліп під музику і 3 вертикальні ролики.
Працює локально на ноутбуці (Windows 11, NVIDIA RTX). Платний лише AI-аналіз кадрів (Gemini Flash) у межах місячного ліміту.

## Встановлення (Windows)

1. Python 3.12+, драйвер NVIDIA, FFmpeg з NVENC у `PATH` (наприклад, збірка gyan.dev «full»).
2. У папці репозиторію:
   ```powershell
   py -3.12 -m venv .venv
   .venv\Scripts\activate
   pip install -e ".[dev]"
   copy .env.example .env    # і заповни ключі
   ```
3. Перевірка системи і створення бази:
   ```powershell
   python -m core check
   python -m core init
   ```
4. Сервер (разом із воркером): `python -m server.app` → http://127.0.0.1:8765/docs
5. Тести: `pytest`

## Введення відео

- **Прямий upload з докачуванням** — протокол tus 1.0 на `/api/uploads`
  (метадані `filename` і `project_id`). Обрив зв'язку не страшний: клієнт продовжує з місця зупинки.
- **Локальний inbox** — поклади файли з карти в `inbox/<назва проєкту>/` (можна з підпапками `DCIM/...`).
  Файл забирається, коли закінчилось копіювання; нова папка створює новий проєкт.
  Службові файли камер (`.LRV`, `.THM`) ігноруються.
- Після прийому: оригінал у `library/<проєкт>/originals/` (лише читання), ffprobe,
  проксі `proxies/<id>_1080.mp4` (монтаж) і `<id>_480.mp4` (Gemini), HDR iPhone → SDR Rec.709.
- «Монтувати»: `POST /api/projects/<id>/edit`, або автоматично через 10 хв без нових файлів.
- Статус черги: `GET /api/queue`.

## Аналіз (локально, безкоштовно)

Після проксі кожне відео проходить етап `analyze_media` (по 480p-проксі):
- **сцени** — PySceneDetect (AdaptiveDetector); сцени довші за 6 с ріжуться на шматки 2–4 с;
- **фільтр браку** — різкість, яскравість, контраст, рух, тряска; причини: кишеня, темрява,
  пересвіт, однотонне, розмито, тряска, закороткий. Пороги — у `styles/filters.json`
  (`standard` і м'якший `lofi`; за замовчуванням `DEFAULT_FILTER_PRESET=lofi`);
- **звук** — гучність у часі і сплески натовпу (≥ 0,5 с, на 6 дБ голосніше фону);
- **мова** — faster-whisper (`WHISPER_MODEL`, на CUDA, якщо є), транскрипт і `.srt`.
  Перший запуск завантажує модель з інтернету.

Результати: `library/<проєкт>/analysis/` і `GET /api/media/<id>/analysis`.

## Структура

```
core/      конфіг, SQLite, перевірка системи
server/    FastAPI, API, авторизація, завантаження
worker/    черга, оркестрація етапів
analysis/  сцени, фільтр, звук, whisper, gemini, кадрування
edit/      вибір кадрів, ритм, вставки, переходи, вертикаль
render/    ffmpeg-фільтри, стилі, NVENC, експорт FCPXML
sources/   прямий upload, Google Drive, локальний inbox
styles/    JSON-пресети стилів і переходів
web/       React PWA, Liquid Glass UI
tests/     юніт-тести
library/   дані користувача (не в git)
```

## Безпека

- Секрети лише в `.env` (не в git).
- Сервер слухає тільки на `127.0.0.1` або Tailscale-адресі; `0.0.0.0` заборонено конфігом.
- Оригінали відео ніколи не змінюються і не видаляються.

## AI-оцінка (Gemini Flash)

- Ключ: `GEMINI_API_KEY` у `.env` (білінговий акаунт з кредитами Google AI Pro). Перевірка: `python -m core gemini-ping`.
- «Монтувати» → `score_project`: шматки, що пройшли локальний фільтр, групуються у вікна відео
  (≤ `GEMINI_WINDOW_SECONDS`) і йдуть одним **Batch**-завданням (−50% вартості). Відповідь — JSON за схемою
  (оцінка 0–10, опис, теги, придатність для вертикалі, тип події); невалідна — одна повторна спроба, далі локальні метрики.
- **Кеш**: оцінка прив'язана до шматка і версії смаку/стилю — повторний монтаж нічого не надсилає.
- **Бюджет**: місячний ліміт `MONTHLY_BUDGET_USD`, вартість кожного запиту за токенами з відповіді,
  резерв під ще не оплачені batch-і, денний ліміт запитів. Прогноз понад `CONFIRM_THRESHOLD_USD` чекає
  підтвердження (`GET /api/confirmations`, `POST /api/jobs/<id>/confirm`). Після ліміту — лише локальні метрики.
- Ціни — у `core/pricing.json`; невідома модель рахується за консервативним `_default`.
- Смак: `taste.md` + картинки-приклади в `library/taste/take/` і `library/taste/skip/` (до 20 у кожній).
- Стан бюджету й історія: `GET /api/budget`.

## Режим 1: кліп під музику

Додай у проєкт трек (mp3/wav/m4a) разом із відео — він аналізується окремо (`analyze_track`):
темп, біти (уточнені до удару, похибка < 1 кадру), сильні долі, енергія, дропи і приспіви.

Після AI-оцінки етап `edit_project` збирає кліп:
- найенергійніший шматок треку заданої довжини (60 с), межі — на початку такту;
- склейки на біт: низька енергія — раз на такт, середня — раз на 2 біти, дроп/приспів — кожен біт;
  кадр-«герой» (9–10, верхні 10% матеріалу) може тримати до 2 тактів;
- вибір кадрів: оцінка + різноманітність (сцена, відео, теги, камери) + хронологія + енергія;
- живі вставки зі сплесків натовпу: 1–3 с, пауза ≥ 8 с, ≤ 4 на хвилину, не на самому дропі;
  трек приглушується на −12 дБ з атакою і відпуском 150 мс;
- результат: `library/<проєкт>/edits/clip_vNNN/` — `timeline.json`, `mix.wav`, `draft.mp4`
  (чорнове 720p, лише склейки; стилі й переходи — Спринт 6).

API: `GET /api/projects/<id>/edits`, `GET /api/edits/<id>/preview`, `GET /api/edits/<id>/timeline`,
`GET|PUT /api/projects/<id>/clip-settings` (довжина, межі треку, вставки, ритм, ваги тегів),
`POST /api/projects/<id>/reedit` — перемонтаж на кешованих оцінках, без запитів у Gemini.
